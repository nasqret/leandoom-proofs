# Lean Doom Lab, first public edition

[Play the game and open the proof theater](https://nasqret.github.io/leandoom-proofs/). Pause a real Hangar or Nuclear Plant run at a theorem, play the authored proof course, or record a new passage with the native Lean port. Seven additional proof scenes have both tiled and original-picture editions. The verification kit includes project skills for Codex and Claude Code.

The exact classic WebAssembly release replayed two independent Ultra-Violence recordings through all nine original Episode One maps. Both visited the secret Military Base and reached the Phobos Anomaly finale. The original IWAD is supplied by the player. All 36 Freedoom: Phase 1 maps are included for immediate play. The native CombatV2 verifier also checked a four-input prefix on every one of them.

The original-map CombatV2 library has whole-passage kernel audits for Hangar and Nuclear Plant. The 4,161-input Computer Station first-exit theorem is compiler-assisted. The nine authored training rooms have 27 kernel-checked routes. A separate stock Lean theorem classifies the two possible complete itineraries in the classic episode's level-successor model.

The student edition includes the executed illustrated notebook, Jupyter Book, Obsidian vault, historical case studies, primary-source bibliography and reproducible exercises.
