Controls & engine

Arrows move and turn, Ctrl fires, Space uses doors and switches. Enter advances menus and intermissions. Press Esc for the game menu. Choose a starting map to start with a pistol, or play from E1M1 through normal and secret exits.

Replay a local input tape with the same engine

From the repository root, use Node.js 22 or later, your own shareware IWAD and an extracted single-player Doom 1.9 LMP. The observer reads map transitions and player state from the unmodified WebAssembly module. The verifier source pins the runtime by SHA-256.

node public-site/classic/replay.cjs public-site/classic /path/to/doom1.wad /path/to/route.lmp result.json

The downloadable JSON records classic engine execution. The CombatV2 verifier checks theorems in Lean for its own input format.
