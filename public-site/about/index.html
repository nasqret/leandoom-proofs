What plays here

The classic player uses Chocolate Doom compiled to WebAssembly, with Freedoom: Phase 1 supplied by the Freedoom contributors. An optional original IWAD is read on the visitor’s device. Each game retains its own maps, graphics and sounds. Chocolate Doom · Freedoom · Pinned build and hashes

The native player runs the pinned Lean port with the CombatV2 arithmetic revision. The browser course uses an independently authored, smaller transition system. The reading room describes exactly which system each theorem covers. Native player · Chapter and bibliography
